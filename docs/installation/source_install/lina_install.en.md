# Lina Environment Deployment

## 1 Lina Component Overview

!!! tip ""
    - [Lina][lina] is the JumpServer frontend UI project, primarily using [Vue][vue] and [Element UI][element_ui].

### 1.1 Environment Requirements

!!! tip ""
    | Component | Version | Node Version |
    | --- | --- | --- |
    | Lina | v4.10.9 | 16.5+ |

### 1.2 Select Deployment Method

!!! tip ""
    === "Source Code Deployment"
        - Download from [GitHub][lina] releases
        - Install dependencies: `npm install`
        - Build: `npm run build`
