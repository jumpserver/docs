# Luna Environment Deployment

## 1 Luna Component Overview

!!! tip ""
    [Luna][luna] is the JumpServer frontend UI project, primarily using [Angular CLI][angular_cli].

### 1.1 Environment Requirements

!!! tip ""
    | Component | Version | Node Version |
    | --- | --- | --- |
    | Luna | v4.10.9 | 16.5+ |

### 1.2 Select Deployment Method

!!! tip ""
    === "Source Code Deployment"
        - Download from [GitHub][luna] releases
        - Install dependencies: `npm install`
        - Build: `npm run build`
